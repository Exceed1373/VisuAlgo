Arti Kode Warna Semantik

Setiap warna pada batang visualisasi dan memori merepresentasikan status komputasi saat runtime:

Idle State
Biru Kehijauan / Cyan

Elemen berada dalam antrean statis dan belum diproses atau diakses oleh penunjuk loop saat ini.

Compare
Kuning Amber

Dua elemen sedang dievaluasi nilai komparasinya (misal: arr[j] > arr[j+1]).

Swap / Mid / Pivot
Coral Oranye / Crimson

Pertukaran posisi nilai dalam memori, penentuan pivot QuickSort, atau indeks median pada Binary Search.

Done / Target Found
Hijau Zamrud

Elemen telah menempati posisi terurut final (in-place sorted) atau nilai pencarian berhasil ditemukan.

Fungsi Tombol & Kontrol Eksekusi

play_arrow
Shortcut: Spasi

Mulai (Play)

Memulai rangkaian visualisasi secara berkesinambungan sesuai kecepatan interval (milidetik) yang ditentukan.

pause
Shortcut: P

Jeda (Pause)

Menghentikan eksekusi sementara tanpa menghapus status memori larik, memungkinkan penelaahan posisi variabel.

step
Shortcut: N / Right

Langkah (Step Debug)

Mengeksekusi tepat 1 operasi komputasi berikutnya. Ideal untuk menganalisis relasi per baris pseudocode dengan larik.

restart_alt
Shortcut: R

Reset State

Mengembalikan urutan dan status seluruh elemen ke konfigurasi awal sebelum algoritma dijalankan.

shuffle
Shortcut: S

Acak Data (Shuffle)

Menghasilkan deretan angka pseudo-random baru secara acak untuk menguji skenario Best Case, Average Case, dan Worst Case.

input
Input Manual

Terapkan Kustom

Memasukkan data angka bebas (contoh: 23, 11, 89, 4) sesuai kasus soal tugas mata kuliah.

verified Spesifikasi Lab Komputer
